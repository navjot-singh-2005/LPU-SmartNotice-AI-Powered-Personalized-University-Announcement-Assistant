# Data Dictionary — LPU SmartNotice

## 1. Raw Announcement Fields (`RawAnnouncement`)
| Field Name | Type | Nullable | Description | Example |
| :--- | :--- | :--- | :--- | :--- |
| `announcement_id` | String | No | Deterministic unique ID generated by system | `ANN-20261001-a1b2c3d4` |
| `title` | String | No | Announcement title | `Mid-Term Exam Seating Plan` |
| `publication_date` | String | No | Date of publication (YYYY-MM-DD) | `2026-10-01` |
| `reference_number` | String | Yes | Official university ref number | `LPU/EXAM/2026/101` |
| `full_content` | String | No | Uncut announcement text body | `All 3rd year students...` |
| `attachment_present` | Boolean | No | Flag indicating if attachment was attached | `true` |
| `attachment_names` | List[String]| No | List of attachment filenames | `["Seating_Plan.pdf"]` |
| `content_hash` | String | Yes | SHA-256 hash of normalized content | `e3b0c44298fc1c149...` |

## 2. Extracted Structured Metadata (`ExtractedAnnouncementMetadata`)
| Field Name | Type | Nullable | Description | Allowed / Example Values |
| :--- | :--- | :--- | :--- | :--- |
| `category` | String | No | Primary announcement category | `ACADEMIC`, `PLACEMENT`, `EXAMINATION`, `EVENT`, `GENERAL` |
| `summary` | String | No | Concise 1-2 sentence factual summary | `Exam seating published for Block 34` |
| `target_year` | List[Int] | No | Targeted academic years | `[3]` or `[]` (all) |
| `target_program` | String | Yes | Specific target degree program | `B.Tech CSE` |
| `target_department` | String | Yes | Target department | `Department of Computer Science` |
| `action_required` | Boolean | No | Indicates if student action needed | `true` |
| `action_type` | Enum | No | Type of action required | `REGISTRATION`, `ATTEND_EVENT`, `NO_CLASS`, `NONE` |
| `urgency` | Enum | No | Urgency level | `CRITICAL`, `HIGH`, `MEDIUM`, `LOW` |
| `global_importance` | Enum | No | University-wide scope | `HIGH`, `MEDIUM`, `LOW` |
| `attachment_present` | Boolean | No | Source attachment flag | `true` |
| `attachment_content_available` | Boolean | No | Whether attachment content parsed | `false` |
| `attachment_dependent` | Boolean | No | Crucial details rely on unparsed file | `true` |
| `decision_completeness` | Enum | No | Completeness status of evidence | `COMPLETE`, `PARTIAL`, `ATTACHMENT_MISSING` |

## 3. Student Profile Fields (`StudentProfile`)
| Field Name | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `student_id` | String | Unique student ID | `STU-101` |
| `name` | String | Student full name | `Aarav Sharma` |
| `program` | String | Enrolled program | `B.Tech Computer Science & Engineering` |
| `department` | String | Academic department | `Department of Computer Science` |
| `school` | String | Enrolled school | `School of Computer Science and Engineering` |
| `year` | Integer | Current academic year (1-4) | `3` |
| `semester` | Integer | Current semester (1-8) | `5` |
| `interests` | List[String] | Key interest topics | `["Web Development", "AI/ML", "Placements"]` |
